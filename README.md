## ✨ Features

- 🎨 **Modern Design** - Glass morphism effects with wine-themed color scheme
- ✨ **Smooth Animations** - GSAP powered scroll reveals and loader animations
- 📱 **Fully Responsive** - Optimized for all device sizes
- 🖱️ **Custom Cursor** - Interactive cursor effects on desktop
- 📧 **Contact Form** - Working contact form with Web3Forms integration
- 🎯 **SEO Ready** - Meta tags and semantic HTML for better searchability
- 🚀 **Fast Performance** - Built with Vite for optimal loading speeds

## 🛠️ Tech Stack

- **Frontend:** React 19, Vite
- **Styling:** CSS3, TailwindCSS (via CDN)
- **Animations:** GSAP (GreenSock Animation Platform)
- **Icons:** Font Awesome, DevIcons
- **Routing:** React Router DOM
- **Deployment:** Vercel
